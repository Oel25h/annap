# Foundation — design-led editorial pass (anti vibe-code)

**Live target:** `/foundation`  
**Date:** 2026-08-29  
**Owner:** design-lead  

## Problem

User rejected prior versions as “vibe coded” (dark split / glow cards / icon pillars) or too empty brochure (centered seal stack).

## Direction

**Content-first editorial** (Sanity discipline + site cream tokens + Stripe Press restraint):

- Left-aligned type, not center-everything  
- Desktop: copy | seal stage grid  
- Mobile: seal first (trust), then left-aligned copy; CTAs full-width  
- Mission / Vision as **own stacked sections** with eyebrow + statement (no duplicate H2 label)  
- Values as quiet chips (mobile) / inline list (desktop) — no numbered cards  
- Stories magazine grid unchanged in spirit  
- Close row: text + CTA side-by-side on desktop  

## Skills used

- `popular-web-designs` (Sanity spacing/hierarchy notes)  
- Site `DESIGN.md` tokens  
- Mobile-first CTA / type scale
